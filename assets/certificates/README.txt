Sertifikat portfolio disimpan dalam format PDF.

Gunakan nama file berikut agar tombol View Certificate pada website berfungsi:

1. linux-unhatched.pdf  -> Sertifikat NDG Linux Unhatched (Cisco Networking Academy)
2. it-essentials.pdf    -> Sertifikat IT Essentials: PC Hardware and Software (Cisco Networking Academy)
3. ccnav7.pdf           -> Sertifikat CCNAv7: Introduction to Networks (Cisco Networking Academy)
4. learn-a-thon.pdf     -> Sertifikat Learn-A-Thon
5. mikrotik.pdf         -> Sertifikat MikroTik / MTCNA

PDF akan dibuka di tab baru ketika pengunjung memilih View Certificate.
