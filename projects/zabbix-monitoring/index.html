// Overview

About This Project

This project was developed during my internship at Diskominfo Cilacap. It focuses on analyzing and implementing a monitoring solution for network infrastructure using Zabbix as the central platform. The goal is to keep the network observable — tracking device availability, interface traffic, and resource usage — while organizing monitoring items through a MITRE ATT&CK-oriented view so that network telemetry can be connected to potential security-relevant activity.

MikroTik RouterOS devices are monitored via SNMP, and alerts are configured for abnormal conditions such as unreachable hosts or unusual traffic patterns, supporting day-to-day network security monitoring activities.

// Implementation

Implementation Highlights

  • Deployed and configured Zabbix on a CentOS server as the central monitoring platform.
  • Added MikroTik RouterOS devices as monitored hosts using SNMP.
  • Collected metrics for device availability, interface traffic, and resource usage.
  • Configured triggers and notifications for abnormal conditions (e.g., host down, unusual traffic).
  • Organized monitoring items following a MITRE ATT&CK-oriented perspective to support security monitoring.
  • Validated the setup from a Kali Linux workstation.

// Approach

Monitoring Approach

1 — Collect

Gather network telemetry from infrastructure devices using SNMP: uptime, interface status, bandwidth, and system resources.

2 — Baseline

Establish what "normal" looks like for the network so deviations in traffic or availability become easier to notice.

3 — Detect & Review

Trigger alerts on abnormal conditions and review events with a MITRE ATT&CK-oriented mindset to connect them to potential adversary behavior.
